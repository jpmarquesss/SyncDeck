# Código de Conduta

O SyncDeck busca uma comunidade respeitosa, colaborativa e segura.

## Comportamento esperado

- Tratar participantes com respeito, independentemente de experiência ou origem.
- Fazer críticas sobre o código e as ideias, nunca sobre a pessoa.
- Explicar problemas com contexto suficiente para que possam ser reproduzidos.
- Preservar dados pessoais, credenciais e informações de dispositivos de terceiros.
- Aceitar decisões técnicas fundamentadas mesmo quando outra solução era preferida.

## Comportamento inaceitável

- Assédio, ameaças, discriminação ou ataques pessoais.
- Publicação de dados pessoais, credenciais ou vulnerabilidades exploráveis.
- Spam, autopromoção sem relação com o projeto ou interrupção deliberada das discussões.
- Uso do projeto para acessar computadores sem autorização.

Problemas de convivência podem ser comunicados aos mantenedores. Vulnerabilidades devem seguir o processo privado de [SECURITY.md](SECURITY.md). Violações podem resultar em remoção de conteúdo ou bloqueio de participação.
