# Suporte

## Dúvidas de uso

Consulte primeiro:

- [README.md](README.md) para instalação e uso.
- [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md) para erros comuns.
- [docs/WAKE-ON-LAN.md](docs/WAKE-ON-LAN.md) para configurar o botão Ligar PC.
- [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) para compilação.
- [docs/RELEASING.md](docs/RELEASING.md) para versões e downloads oficiais.
- [INSTALAR-NO-IPHONE.txt](INSTALAR-NO-IPHONE.txt) para gerar, assinar, instalar e renovar o app no iPhone sem Mac.

Se o problema continuar, abra uma issue usando o modelo **Relatar problema** e inclua:

- versão do SyncDeck;
- versão do Windows e do Android/iOS;
- modelo do celular;
- passos para reproduzir;
- mensagem de erro completa;
- trecho relevante do Logcat ou mensagem exibida no iPhone, sem dados pessoais ou chaves;
- nome do job que falhou no GitHub Actions, se o problema for uma compilação.

Antes de anexar logs ou imagens, remova IP, MAC, fingerprint, código de pareamento, caminhos pessoais, e-mails e informações bancárias.

## Segurança

Não abra issue pública para vulnerabilidades ou exposição de credenciais. Use o processo de [SECURITY.md](SECURITY.md).

## Limites

O projeto é distribuído sem garantia. Os mantenedores podem orientar sobre o código oficial, mas não conseguem validar APKs ou executáveis recompilados por terceiros.
