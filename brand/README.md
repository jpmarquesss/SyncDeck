# Identidade visual do SyncDeck

Esta pasta contém os arquivos oficiais da marca. O símbolo representa quatro botões de um painel digital e deve ser mantido inclinado em `-8°`.

## Arquivos

- `syncdeck-logo.svg`: versão horizontal para cabeçalhos, documentação e divulgação.
- `syncdeck-mark.svg`: ícone quadrado sobre fundo escuro para aplicativos e agente Windows.
- `syncdeck-mark-transparent.svg`: símbolo isolado para interfaces e fundos controlados.
- `syncdeck-social-preview.png`: capa para compartilhamento do site e do repositório.

## Cores

| Uso | Cor |
|---|---|
| Verde principal | `#72F5AD` |
| Verde secundário | `#50AA78` |
| Fundo | `#070A09` |
| Texto | `#F5F8F6` |

Não alterar a ordem das cores, retirar o espaçamento entre os quatro botões nem aplicar o símbolo sobre fundos com pouco contraste.
